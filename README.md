# ZenoFCIS

ZenoFCIS is a high-assurance Rust library family for functional-core / imperative-shell systems.

The project treats state, commands, evidence, decisions, patches, effect plans, receipts, composition contracts, and commit bundles as immutable values. Protocol meaning belongs in a pure deterministic core; databases, clocks, networks, retries, and delivery belong in an imperative shell.

The repository is being bootstrapped through reviewable pull requests. No production-readiness or protocol-authority claim is made by the initial workspace.
