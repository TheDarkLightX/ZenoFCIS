# Count and bound finite risk

Read the question, complete status and witnesses in that order.

```sh
zeno-fcis contract risk examples/quantitative-risk/swap-pool --reward 610 --steps 3 --format json
```

Expected: exit 0, best 0 and worst 6, including a length-3 witness.
Use --where for declared inputs; add --states --steps for distinct reachable states.
UNKNOWN claims nothing. The packet grants no runtime or publication authority.
